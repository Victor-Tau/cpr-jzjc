# v2.1.2：适配 CPR 3.55.3

宿主范围：`>=3.55.3,<3.56.0`。平台：Linux x86_64 / ARM64（aarch64），glibc 2.36+。

SDK 与官方打包工具固定至 CPR v3.55.3 提交 `ef45165d8d30cfaee65558807b401541503d8aea`。对照 v3.54.0，SDK 变化集中于运行设置、定价目录和中间件文档，插件未使用这些接口；manifest v2、RPC v7、管理能力 v2、维护能力 v1 及现有私有状态 schema 无变化，检测功能不变。

通过宿主更新现有插件实例，可保留配置、计划、检测历史及指纹库。

| 宿主架构 | 安装包 |
| --- | --- |
| x86_64 | `personal.modeltrace-health-2.1.2-x86_64-unknown-linux-gnu.tar.gz` |
| ARM64 | `personal.modeltrace-health-2.1.2-aarch64-unknown-linux-gnu.tar.gz` |

由 GitHub Actions 在两种架构的原生 runner 上编译、验证并发布安装包及 SHA-256 摘要。验证范围见[验证记录](../verification.md)。
