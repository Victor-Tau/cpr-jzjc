# v1.5.1

适配 Codex Proxy RS 3.29.7 的插件 RPC v5，删除1.5.0引入的用量与费用显示。

- SDK 与 `cpr-plugin` 打包工具使用宿主3.29.7的同一发布提交 `78bc57c5cf24b01a38e985cdd739bb4ae89ce11f`，重新编译并打包；指纹库下载适配字节形式的 HTTP 头和新版响应元数据。
- UI 组件包更新至 `@codex-proxy/ui` 0.5.0，构建工具链更新至 Rust 1.99.1，前端使用 Node 24。
- 账户列表、检测历史与报告不再显示费用；移除费用查询接口、金额汇总、前端轮询和后台同步。
- 保留约29秒请求窗口、及时评分和部分结果接纳；插件 ID 与状态 schema 不变，更新原实例保留配置、自动计划、指纹库、检测历史和提交去重，兼容旧记录中的费用字段。

适配 **Codex Proxy RS >=3.29.7、<3.30.0**，Linux x86_64、glibc 2.36+。宿主3.29.0–3.29.6使用RPC v4，请继续使用原有兼容版本。

下载附件 `personal.modeltrace-health-1.5.1-x86_64-unknown-linux-gnu.tar.gz`，在宿主插件管理中更新并切换现有实例。包含私有 Python/NumPy 评分运行时，无需额外安装 Python。

安装包 SHA-256：`2f0d7a151596c751f7e66ca2e136d585a232d73ca304abe3b89f8a5089083bec`。
