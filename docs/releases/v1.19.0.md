# v1.19.0 — 适配 CPR 3.43.0，配置检测失败处理与重试

- 宿主版本：`>=3.43.0,<3.44.0`，SDK 与官方打包工具固定至 CPR v3.43.0（`402bc37fbb5c83378cc83cec89e9fa251e4a99c1`）。
- 参数配置新增「失败后重试（次）」：0–99，默认 4。表示每轮首次请求失败后追加的重试次数；0 为只请求一次。认证、Key 权限、模型参数拒绝及超时也使用此预算，沿用已配置的重试间隔。
- 参数配置新增「请求被拒绝后的处理」：耗尽重试后，可选择保留调度、下次继续自动检测，或停止该账户调度。默认保留；继续自动检测需启用定时计划或配置请求日志触发。
- 停用前核对账户身份，操作失败可在报告中单独重试；失败保留原结论与原因，不记为降智，不触发移组。普通网络故障、限流、超时和无效样本不触发此项停用。
- JSON 配置字段为 `failureRetries`（0–99）和 `requestRejectedAction`（`continue` / `disable`），配置备份支持导入、导出。任务沿用提交时的配置及重试次数，重启后继续。
- 保留 RPC v7、管理能力 v2、180 秒维护预算与私有状态 schema，同实例升级保留配置、计划、历史及指纹库。旧配置补齐默认值。

## 安装与升级

下载 `personal.modeltrace-health-1.19.0-x86_64-unknown-linux-gnu.tar.gz`，在 CPR 插件管理中上传并切换现有实例。要求 Linux x86_64、glibc 2.36+，已内置 Python/NumPy 评分运行时；校验文件为同名 `.sha256`。

升级后在「参数配置 → 判定与复测」设置失败重试次数和请求拒绝后的处理，点击「保存全部参数」。详细规则见[使用指南](../usage.md)，验证范围见[验证记录](../verification.md)。
