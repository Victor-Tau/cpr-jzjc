# v1.9.0

适配 **Codex Proxy RS 3.33.0**：使用官方 `v3.33.0` 标签对应提交 `8c8618aa0f841638262262e3338c115bc075f125` 的 SDK 和打包工具重新编译，插件通信升级为 **RPC v7**。3.33.0 宿主仅支持 v7，旧插件包需更新。

前端 UI 组件库同步更新至宿主使用的 `@codex-proxy/ui` 0.7.0，并刷新依赖锁文件和第三方许可。

新版 SDK 在等待宿主回调时归还执行名额，取得宿主恢复授权后继续处理，并释放已消费的回调结果。保留 180 秒维护预算、现有检测功能和状态 schema；更新现有实例保留配置、计划、历史、指纹库和提交去重。

适用于 **Codex Proxy RS >=3.33.0、<3.34.0；Linux x86_64、glibc 2.36+**。包含私有 Python/NumPy 评分运行时。

安装包：`personal.modeltrace-health-1.9.0-x86_64-unknown-linux-gnu.tar.gz`。在宿主「插件管理」上传安装包并更新现有实例。

前端、Rust 发布二进制和官方打包工具全部绑定 CPU 0，使用一个核心编译。

验证范围和结果见 [验证记录](https://github.com/Victor-Tau/cpr-jzjc/blob/v1.9.0/docs/verification.md)。
