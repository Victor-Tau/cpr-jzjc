# v2.1.8 新增 macOS ARM64 安装包

兼容 CPR 3.54.x 至 3.58.x，清单范围为 `>=3.54.0,<3.59.0`。SDK 和打包工具固定到 CPR v3.58.0。

| 宿主系统 | 安装包 |
| --- | --- |
| Linux x86_64（glibc 2.36+） | `personal.modeltrace-health-2.1.8-x86_64-unknown-linux-gnu.tar.gz` |
| Linux ARM64（glibc 2.36+） | `personal.modeltrace-health-2.1.8-aarch64-unknown-linux-gnu.tar.gz` |
| macOS ARM64（Apple 芯片） | `personal.modeltrace-health-2.1.8-aarch64-apple-darwin.tar.gz` |

每个安装包附有 `.sha256` 校验文件。在 CPR 插件管理中上传对应平台的安装包，把现有实例切换到 2.1.8 可保留配置、计划、检测历史和指纹库。
