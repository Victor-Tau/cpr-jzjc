# 账号降智检测 1.4.0

新增降智后移组及配置备份，沿用1.3的检测性能、实时进度和时区逻辑。

- 默认参数：低置信度复测阈值 **20%**、降智判定阈值 **90%**、连续确认 **1轮**、低置信度额外复测 **1次**、重试间隔 **10秒**、历史保留 **30天**。
- 确认降智后可分别开启「关闭账户调度」与「移入指定分组」，支持同时开启。移组替换原有全部分组，支持选择空分组。
- 两项操作独立保存结果，失败不阻止另一项；报告支持单独重试，无需重新检测。执行前后核对账户身份与结果，重试发现已到目标状态时跳过重复写入。
- 参数自动保存在宿主；更新原插件实例保留配置。新增 `modeltrace-health-config.json` 导出和导入，导入先校验并载入表单，核对后保存才生效，便于重装或迁移。宿主隔离页面提供可复制的完整 JSON，可保存为同名配置文件。
- 旧配置保留原有参数，新增移组选项默认关闭；可点击「使用 1.4 默认规则」后保存采用本版默认值。

适用于 **Codex Proxy RS >=3.29.1、<3.30.0；Linux x86_64、glibc 2.36+**。上传附件中的 `personal.modeltrace-health-1.4.0-x86_64-unknown-linux-gnu.tar.gz` 更新现有实例，`.sha256` 附件用于校验。包内包含 Python/NumPy，无需另外部署 ModelTrace。

同实例更新保留已有配置与历史；删除后新建实例需要导入备份，备份不含密钥、账号凭据、历史或指纹库。已提交任务继续使用原配置快照。确认后的调度与移组操作由宿主维护回调执行，仍受其调度间隔影响。

验证：11项Rust、6项Python、30项发布二进制RPC集成、1.3→1.4真实二进制配置继承及浏览器交互（含宿主iframe隔离）通过。验证范围与复现命令见仓库 `docs/verification.md`。集成使用真实发布二进制、模拟宿主和模型事件，未发送真实账户检测请求。
