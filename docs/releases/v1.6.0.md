# v1.6.0

检测历史支持全选与批量删除，自动定时检测的订阅类型改为多选。

- 检测历史新增选择列和「全选筛选结果」，按当前搜索与结论筛选选择全部可删除记录；翻页后已选记录保留，可跨页累积后一次删除。
- 正在检测、排队中或等待关闭调度、移组的记录不可选择；批量删除同时返回已删除与跳过数量，并在界面提示。
- 批量删除只移除历史与报告，不恢复已停用账户，也不改变账户分组或调度状态；原有单条删除保持不变。
- 自动定时检测的订阅类型改为多选，可同时匹配多个订阅；留空表示全部订阅。旧配置中的单一订阅值在界面打开时自动带入多选，检测行为保持不变。
- `api/delete` 继续接受 `{id}`，新增 `{ids}` 批量形式并返回 `deleted`、`skipped`。插件 ID 不变，新增的定时订阅多选字段向后兼容旧配置与状态。

适配 **Codex Proxy RS >=3.29.7、<3.30.0**，Linux x86_64、glibc 2.36+。
