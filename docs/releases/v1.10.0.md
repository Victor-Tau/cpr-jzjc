# v1.10.0 · CPR 3.35 适配与管理响应修复

适配 **Codex Proxy RS >=3.35.0、<3.36.0**，SDK 与官方打包工具固定至 `v3.35.0` 对应提交 `80f7d53085f5c9552e7e74b796a0bec50586ee1b`，继续使用 RPC v7。

修复「插件管理响应状态、内容类型或正文无效」：历史、账户或模型列表过大时，管理响应可能超过宿主的 1 MiB 正文上限。新版按 UTF-8 编码后的实际字节数分页，前端自动合并完整列表；分页期间数据发生变化会重新读取，避免重复或遗漏。单条内容异常过大时返回可读错误。

保留 180 秒维护预算、三天历史、现有配置、计划、指纹库与状态 schema。前端、Rust 插件和同版官方打包工具均绑定 CPU 0，使用单个核心编译。

安装包：`personal.modeltrace-health-1.10.0-x86_64-unknown-linux-gnu.tar.gz`，另附 `.sha256`。适用于 Linux x86_64、glibc 2.36+，包含私有 Python/NumPy 评分运行时。在宿主「插件管理」上传安装包并更新现有实例。

73 项 RPC、20 项 Rust、6 项 Python 评分测试，以及前端请求、浏览器、安装包和升级保留验证均通过。详情见 [验证记录](https://github.com/Victor-Tau/cpr-jzjc/blob/v1.10.0/docs/verification.md)。集成使用实际插件进程与模拟宿主，未在生产宿主部署。
