# v1.15.0 — 适配 CPR 3.39.1，按账号保留检测记录

- 宿主版本：`>=3.39.1,<3.40.0`。
- SDK 与官方打包工具固定至 CPR v3.39.1（`12c32fcdecb29da4e44a21bb33fbbf2aaf6a166d`）。
- 历史不再固定保留 3 天，改为每个账户保留最近 N 条检测记录（参数配置「每账号保留检测记录数」，默认 10，范围 1–100）。活动任务及等待账户处理的记录不会被清理。
- 继续使用 RPC v7、管理能力 v2、UI 0.8.0 与原有私有状态 schema，现有配置、历史和指纹库保留。

## 安装与升级

下载 `personal.modeltrace-health-1.15.0-x86_64-unknown-linux-gnu.tar.gz`，在 CPR 插件管理中上传并切换现有实例。要求 Linux x86_64、glibc 2.36+。
