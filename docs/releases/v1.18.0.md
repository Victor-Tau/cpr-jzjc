# v1.18.0 — 适配 CPR 3.42.0

- 宿主版本：`>=3.42.0,<3.43.0`。
- SDK 与官方打包工具固定至 CPR v3.42.0（`7cee4309473949115610288fb7f29b3346e470c2`）。
- 核对新版 SDK 的独立排队超时和排队失败换号字段；插件未调用运行设置接口，检测仍绑定所选账户。
- 继续使用 RPC v7、管理能力 v2、180 秒维护预算和兼容的运维错误日志接口。
- 私有状态 schema 保持兼容，同实例升级保留配置、计划、检测历史及指纹库。

## 安装与升级

下载 `personal.modeltrace-health-1.18.0-x86_64-unknown-linux-gnu.tar.gz`，在 CPR 插件管理中上传并切换现有实例。要求 Linux x86_64、glibc 2.36+，已内置 Python/NumPy 评分运行时。

校验文件为同名 `.sha256`。请使用 Release 附件中的安装包。

验证结果与范围见 [验证记录](../verification.md)。
