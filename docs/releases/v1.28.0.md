# v1.28.0：适配 CPR 3.53.1

宿主范围：`>=3.53.1,<3.54.0`。平台：Linux x86_64 / ARM64（aarch64），glibc 2.36+。

SDK 与官方打包工具固定至 CPR v3.53.1 提交 `188a6817d141a8d9a1a0bceead4f07477d35276e`。与 v3.52.2 相比，官方插件 SDK、运行时生产代码、打包器生产代码及宿主插件兼容合同均未变化；插件继续使用 manifest v2、RPC v7、管理能力 v2、维护能力 v1 及现有私有状态 schema。

CPR 新增的请求记录错误来源筛选不改变插件使用的 `/api/admin/operations/errors` 接口。新版账户选择器仍按所选账户执行绑定检测，无需修改插件业务代码。

通过宿主更新现有插件实例，可保留配置、计划、检测历史及指纹库。发布后请按 CPR 宿主架构下载安装包及对应 `.sha256`：

| 宿主架构 | 安装包 |
| --- | --- |
| x86_64 | `personal.modeltrace-health-1.28.0-x86_64-unknown-linux-gnu.tar.gz` |
| ARM64 | `personal.modeltrace-health-1.28.0-aarch64-unknown-linux-gnu.tar.gz` |
