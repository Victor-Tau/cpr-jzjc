# v1.7.3

使用 Codex Proxy RS 3.31.1 的新版 SDK 和同版打包工具重新编译插件。

- SDK 固定至官方 `v3.31.1` 标签对应提交 `06e1d8f0ac33d8633198d837c4f9017ad466f358`。
- 宿主兼容范围更新为 **Codex Proxy RS >=3.31.1、<3.32.0**。
- RPC v5、管理能力 v2、维护能力 v1 和私有状态 schema 延续现有版本；更新现有实例保留配置、计划、历史、指纹库和提交去重。
- 前端同步更新宿主版本提示；全部编译通过 `taskset -c 0` 绑定 CPU 0，Cargo 并发数为 1。

发布包适用于 Linux x86_64、glibc 2.36+，包含私有 Python/NumPy 评分运行时。

下载 `personal.modeltrace-health-1.7.3-x86_64-unknown-linux-gnu.tar.gz` 及对应 `.sha256`，在 CPR 插件管理中上传并更新现有实例。

构建、回归和升级验证见[验证记录](https://github.com/Victor-Tau/cpr-jzjc/blob/v1.7.3/docs/verification.md)。
