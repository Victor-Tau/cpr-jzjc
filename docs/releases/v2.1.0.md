# v2.1.0：移回正常与两种降智判定规则

宿主范围：`>=3.53.1,<3.54.0`。平台：Linux x86_64 / ARM64（aarch64），glibc 2.36+。

## 新增

- **移回正常**：账户检测页每行「检测」右侧新增「移回正常」按钮，把账户移入配置的正常分组（替换原有全部分组），不改变账户调度状态。账户已在正常分组、正在检测或等待关闭调度/移组时不可操作。
- **正常分组**：在「参数配置 → 确认降智后的处理」选择；保存时校验分组存在。未选择时不显示「移回正常」按钮。
- **降智判定规则（二选一）**：
  - 出现降级模型（默认，与之前一致）：最高候选在降级模型名单内即命中。
  - 与目标模型不匹配：最高候选与目标模型（请求模型经别名映射后）不一致即命中，不使用降级模型名单。目标模型须在当前指纹库内，可用别名映射（例如 `gpt-6.1-sol=gpt-6-sol`）。此规则更严格，建议配合连续确认轮数 ≥2。
- 报告配置快照显示所用判定规则。

## 升级说明

通过宿主更新现有插件实例，配置、计划、检测历史和指纹库全部保留；旧配置默认使用「出现降级模型」规则，行为不变。
