# v1.8.0

适配 Codex Proxy RS 3.32.0 的 RPC v6 和分阶段调用预算。

- SDK 固定至官方 `v3.32.0` 标签对应提交 `6a5300a7b5c649f2a6d548df70ccdd58d15e0025`，使用同版 `cpr-plugin` 打包。
- 宿主兼容范围为 **>=3.32.0、<3.33.0**。RPC v6 不兼容旧宿主，升级宿主和插件需配套进行。
- 维护阶段显式声明 180 秒，执行器读取 SDK 共享期限的剩余预算；默认 120 秒模型请求有额外的准备与收尾空间。
- 原来约 30 秒就结束的慢模型请求可以继续等待；自定义更长超时仍受有限维护预算和独立网络期限约束。0 不代表无限维护。
- 管理能力 v2、维护能力 v1、私有状态 schema 和评分算法保持不变。更新现有实例保留配置、计划、历史和指纹库；已经结束的失败或中断任务需重新提交。

发布包适用于 Linux x86_64、glibc 2.36+，包含私有 Python/NumPy 评分运行时。

安装包：`personal.modeltrace-health-1.8.0-x86_64-unknown-linux-gnu.tar.gz`，另附 `.sha256`。在 CPR 插件管理中上传安装包并更新现有实例。

已通过 70 项 RPC 回归、17 项 Rust 单元测试、6 项 Python 评分测试、浏览器检查，以及 1.7.3 → 1.8.0 升级保留验证。长请求实测覆盖四路并行 31 秒响应和单次 121 秒响应，均正常完成；测试使用实际发布二进制与模拟宿主，未在生产宿主部署。完整结果见 [验证记录](https://github.com/Victor-Tau/cpr-jzjc/blob/v1.8.0/docs/verification.md)。
