# v2.1.3 适配 CPR 3.56.0

支持 CPR 3.54.x、3.55.x 和 3.56.x，清单兼容范围为 `>=3.54.0,<3.57.0`。SDK 和官方打包工具固定到 [CPR v3.56.0](https://github.com/zyycn/codex-proxy-rs/releases/tag/v3.56.0) 提交 `a46d0f4c08bcf0f89aa004eb1d089e9e0039898c`。

在 CPR 插件管理中上传对应架构的安装包，再将现有插件实例切换到 2.1.3，可保留配置、计划、检测历史和指纹库。

| Linux 宿主架构（glibc 2.36+） | 安装包 |
| --- | --- |
| x86_64 | `personal.modeltrace-health-2.1.3-x86_64-unknown-linux-gnu.tar.gz` |
| ARM64 | `personal.modeltrace-health-2.1.3-aarch64-unknown-linux-gnu.tar.gz` |

安装包随附 `.sha256` 校验文件。[验证记录](https://github.com/Victor-Tau/cpr-jzjc/blob/v2.1.3/docs/verification.md)
