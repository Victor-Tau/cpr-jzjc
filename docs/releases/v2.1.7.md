# v2.1.7 适配 CPR 3.58.0

兼容 CPR 3.54.x 至 3.58.x，清单范围为 `>=3.54.0,<3.59.0`。插件 SDK 和官方打包工具固定到 [CPR v3.58.0](https://github.com/zyycn/codex-proxy-rs/releases/tag/v3.58.0) 提交 `91d3b8cad88683aeaee161d6df455b03be48d0cd`。

在 CPR 插件管理中上传对应架构的安装包，将现有插件实例切换到 2.1.7，可保留配置、计划、检测历史和指纹库。

| Linux 宿主架构（glibc 2.36+） | 安装包 |
| --- | --- |
| x86_64 | `personal.modeltrace-health-2.1.7-x86_64-unknown-linux-gnu.tar.gz` |
| ARM64 | `personal.modeltrace-health-2.1.7-aarch64-unknown-linux-gnu.tar.gz` |

每个安装包附有 `.sha256` 校验文件。[验证记录](https://github.com/Victor-Tau/cpr-jzjc/blob/v2.1.7/docs/verification.md)
