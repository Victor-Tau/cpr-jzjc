# v1.22.0：适配 CPR 3.45.1

宿主范围：`>=3.45.1,<3.46.0`。平台：Linux x86_64 / ARM64（aarch64），glibc 2.36+。

SDK 与官方打包工具固定至 CPR v3.45.1 提交 `431992a7a43be32a0fad2fbc8a554732096fa299`。继续使用 RPC v7、管理能力 v2、180 秒维护预算和 UI 0.8.0。

- 账户页状态显示、状态筛选及定时检测范围支持宿主新增的 `quota_paused`（额度暂停）状态。宿主在额度暂停期间不向该账户发送新请求，对这类账户的检测会失败；可在定时检测范围中将状态设为「正常」，避开这类账户。
- 核对官方新增的 Client Key 显式预算窗口、Anthropic Messages 入口和账户额度上限。插件使用的账户、分组、批量更新、运维错误日志、模型目录及绑定账户模型请求接口保持兼容，插件不使用新增预算接口。

通过宿主更新现有插件实例，可保留配置、计划、检测历史及指纹库。失败重试、请求拒绝处理及历史保留行为沿用 1.21.0。
