# 账号降智检测 1.4.3

账户页顶部新增自动检测状态：是否开启、检测周期，以及下一次检测时间并标注来源（自动/手动）。检测行为与1.4.2完全一致，仅新增展示。

- 顶部状态条：绿色「自动检测 · 每 30 分钟」、灰色「自动检测 · 已关闭」；每日制显示「每日 03:00」。
- 下次检测：取定时下一次执行与活动任务下一次执行中较早者，随后标注「（自动）」或「（手动）」；正在进行显示「现在」，当天只显示时刻、跨天显示「明天 06:10」，悬停可见完整时间与时区。
- 新增浏览器回归：覆盖开启、关闭、手动任务运行三种状态。展示数据全部来自现有接口，未改动后端与调度。

上传附件 `personal.modeltrace-health-1.4.3-x86_64-unknown-linux-gnu.tar.gz` 更新现有实例，`.sha256` 用于校验。适用于 **Codex Proxy RS >=3.29.1、<3.30.0；Linux x86_64、glibc 2.36+**，内含 Python/NumPy，无需另外部署 ModelTrace。本次改进不要求更新宿主。

验证：11项Rust、6项Python、34项发布二进制RPC集成、1.3.0/1.4.0/1.4.1/1.4.2→1.4.3升级和浏览器交互均通过。验证结果和复现命令见仓库 `docs/verification.md`。集成使用实际发布二进制与模拟宿主、模型流，未发送真实账户检测请求。
