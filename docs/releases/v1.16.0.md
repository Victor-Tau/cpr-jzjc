# v1.16.0 — 适配 CPR 3.40.0

- 宿主版本：`>=3.40.0,<3.41.0`。
- SDK 与官方打包工具固定至 CPR v3.40.0（`789609dd53663b323e43567d2476f7f83b6b77a1`）。
- 核对上游变更：新增用量扫描与统计读取能力；本插件使用的管理、维护、账户、模型及私有状态合同保持兼容，继续使用 RPC v7、管理能力 v2 与 180 秒维护预算。
- 私有状态 schema 与检测行为保持不变，同实例升级保留配置、计划、检测历史和指纹库。

## 安装与升级

下载 `personal.modeltrace-health-1.16.0-x86_64-unknown-linux-gnu.tar.gz`，在 CPR 插件管理中上传并切换现有实例。要求 Linux x86_64、glibc 2.36+。

校验文件为同名 `.sha256`。请使用 Release 附件中的安装包。

验证结果与范围见 [验证记录](../verification-v1.16.0.md)。
