# v1.4.5

自动检测与手动检测按来源独立管理，检测来源改为显示在检测时间后面。

- 同一账户可各有一个活动手动任务和自动任务，分别去重、重试、复测并保留报告；两类就绪任务交替执行。
- 自动检测不再阻止手动检测按钮和批量选择，手动检测不再使自动计划跳过该账户。
- 「停止手动队列」和「停止自动队列」分别取消对应任务，互不取消，也不改变自动计划；运行中的取消仍即时生效。
- 账户列表与检测历史的时间后显示「（手动）」或「（自动）」；顶部「下次检测」只取自动计划时间，不再附加来源或混入手动重试时间。
- 保持插件 ID 和状态 schema，原实例升级保留参数、历史、指纹库和自动计划，兼容旧版提交的幂等重试。

适配 Codex Proxy RS >=3.29.1、<3.30.0，Linux x86_64、glibc 2.36+。上传 `personal.modeltrace-health-1.4.5-x86_64-unknown-linux-gnu.tar.gz` 更新现有实例。
