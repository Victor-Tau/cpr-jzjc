# v1.4.6

接纳通过样本校验的部分正文，分别统计正文与推理字节，并减少确认降智后移组及后续检测的调度等待。

- 达到宿主预算、配置超时、输出 token 上限或流正常关闭但没有完成事件时，保留已收到的正文；丢弃末尾可能未输出完整的数字，再按原有有效数字门槛校验，通过后继续评分。报告标记「已接纳部分结果（样本校验通过）」。
- 只有推理内容、有效数字不足、明确上游失败、内容过滤、协议错误和管理员取消时不接纳。采样及降智判断门槛保持原值。
- 实时进度及成功、失败的请求记录分别显示正文、可见推理/摘要的 UTF-8 字节数和流数据总量，完成快照不与增量重复统计。隐藏推理未返回时无法按字节统计；历史记录缺少分类统计时仅显示已有总量。
- 收到完成事件立即结束接收，不再额外等待流关闭。预算充足时在同一次维护回调内完成评分、关闭调度、移组和后续账户检测；自动更新检查安排在空闲回调。单个任务每次回调仍最多推进一轮或一次失败尝试。
- 后续账户按剩余预算执行，缩短窗口的超时保留普通重试次数；完整窗口连续两次宿主预算超时仍提前终止。账户操作也受当前预算限制，超时保存失败原因，重试先校验现状，避免重复修改。
- 插件 ID 和状态 schema 不变，原实例升级保留配置、历史、自动计划和指纹库。宿主30秒维护预算仍然存在，持续推理而未产出足够正文时仍可能超时。

适配 Codex Proxy RS >=3.29.1、<3.30.0，Linux x86_64、glibc 2.36+。上传 `personal.modeltrace-health-1.4.6-x86_64-unknown-linux-gnu.tar.gz` 更新现有实例。
