# v2.1.4 适配 CPR 3.57.0

支持 CPR 3.54.x 至 3.57.x，清单兼容范围为 `>=3.54.0,<3.58.0`。SDK 和官方打包工具固定到 [CPR v3.57.0](https://github.com/zyycn/codex-proxy-rs/releases/tag/v3.57.0) 提交 `6950c02ee460143dd63103a35a5dd679712488dc`。

在 CPR 插件管理中上传对应架构的安装包，再将现有插件实例切换到 2.1.4，可保留配置、计划、检测历史和指纹库。

| Linux 宿主架构（glibc 2.36+） | 安装包 |
| --- | --- |
| x86_64 | `personal.modeltrace-health-2.1.4-x86_64-unknown-linux-gnu.tar.gz` |
| ARM64 | `personal.modeltrace-health-2.1.4-aarch64-unknown-linux-gnu.tar.gz` |

安装包随附 `.sha256` 校验文件。[验证记录](https://github.com/Victor-Tau/cpr-jzjc/blob/v2.1.4/docs/verification.md)
