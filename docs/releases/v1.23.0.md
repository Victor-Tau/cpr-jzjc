宿主范围：`>=3.47.0,<3.48.0`。平台：Linux x86_64 / ARM64（aarch64），glibc 2.36+。

SDK 与官方打包工具固定至 CPR v3.47.0 提交 `0e02a056b5a4fcb9fe204e741cbc20575041d7ba`。继续使用 manifest v2、RPC v7、管理能力 v2、维护能力 v1、180 秒维护预算及 UI 0.8.0；插件使用的账户、分组、模型目录和运维错误日志接口保持兼容，私有状态 schema 不变。
