# v1.21.0：新增 Linux ARM64 支持

宿主范围：`>=3.44.0,<3.45.0`（与 1.20.0 相同）。平台：Linux x86_64 / ARM64（aarch64），glibc 2.36+。

本版本新增 ARM64 安装包，业务逻辑、评分算法、RPC v7、管理能力 v2 与私有状态 schema 均与 1.20.0 一致。SDK 与官方打包工具仍固定至 CPR v3.44.0 提交 `c622f085748f812936a7371fcc85d1621fa72ca8`。

- 后端按编译目标选择私有 Python 的动态加载器与库目录。
- 私有运行时按架构固定 Python 3.11.17 基础镜像与 NumPy 2.4.3 wheel 摘要，构建、复用和最终校验都会核对 ELF 架构。
- 两种安装包均由 GitHub Actions 在原生 runner 的 Debian 12 容器内构建，通过单元测试、产物校验、冷启动评分及 82 项 RPC 回归后发布。

请按 CPR 宿主架构下载安装包及对应 `.sha256`：

| 宿主架构 | 安装包 |
| --- | --- |
| x86_64 | `personal.modeltrace-health-1.21.0-x86_64-unknown-linux-gnu.tar.gz` |
| ARM64 | `personal.modeltrace-health-1.21.0-aarch64-unknown-linux-gnu.tar.gz` |

通过宿主更新现有插件实例，可保留配置、计划、检测历史及指纹库。

ARM64 支持由 @mfandcc 贡献（#5）。验证结果见 [验证记录](../verification.md)。未在生产 CPR 宿主安装，未访问真实账户；ARM64 宿主上的使用问题欢迎反馈。
