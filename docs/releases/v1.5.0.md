# v1.5.0

- 请求时间上限由约28秒调整为约29秒（宿主每次维护回调30秒）。
- 删除前端进度和请求记录中的「推理 x.x KB」，「未命中降智规则」改为「未降智」。
- 请求前预加载指纹库，有效样本按实际剩余预算立即评分，避免固定预留6秒导致等待下一次回调。仅在预算不足时保存样本，下次优先评分，不重复发起请求。
- 检测结束后，在账户列表、历史和报告的结果同一行右侧显示检测费用。通过本次各个请求ID读取平台使用统计，精确汇总全部尝试、失败重试和复测，按币种分别显示；已知零费用显示0，未返回完整费用显示「待同步」并自动补全。费用查询有独立超时，不阻止检测完成。
- 插件ID和状态schema保持不变，现有配置、自动计划、指纹库和历史保留；历史记录可按已有请求ID补全费用。

适配 Codex Proxy RS >=3.29.1、<3.30.0，Linux x86_64、glibc 2.36+。上传 `personal.modeltrace-health-1.5.0-x86_64-unknown-linux-gnu.tar.gz` 更新现有实例。
