# v1.26.0：适配 CPR 3.51.0

宿主范围：`>=3.51.0,<3.52.0`。平台：Linux x86_64 / ARM64（aarch64），glibc 2.36+。

SDK 与官方打包工具固定至 CPR v3.51.0 提交 `ba2afe67d04755a247a9d534115ac168d4db7478`。与 v3.49.0 相比，官方插件 SDK 将调度能力升至 v4（候选新增会话绑定与角色字段）并新增额度历史查询接口；打包器、manifest v2、RPC v7 合同不变。插件不使用调度能力和额度历史接口，继续使用管理能力 v2、维护能力 v1 及现有私有状态 schema，无需修改插件业务代码。

通过宿主更新现有插件实例，可保留配置、计划、检测历史及指纹库。请按 CPR 宿主架构下载安装包及对应 `.sha256`：

| 宿主架构 | 安装包 |
| --- | --- |
| x86_64 | `personal.modeltrace-health-1.26.0-x86_64-unknown-linux-gnu.tar.gz` |
| ARM64 | `personal.modeltrace-health-1.26.0-aarch64-unknown-linux-gnu.tar.gz` |

验证结果见[验证记录](../verification-v1.26.0.md)。
