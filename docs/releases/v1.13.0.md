# v1.13.0 — 适配 CPR 3.38.1

- 宿主版本：`>=3.38.1,<3.39.0`。
- SDK 与官方打包工具固定至 CPR v3.38.1（`e0b7a841ca074f17e11dad73f39a159c75cb2fb1`）。
- 核对新版宿主的模型调度与插件接口，继续通过宿主绑定账户及计量 Key 执行检测。
- 继续使用 RPC v7、管理能力 v2、180 秒维护预算、UI 0.8.0 与原有私有状态 schema。

## 安装与升级

下载 `personal.modeltrace-health-1.13.0-x86_64-unknown-linux-gnu.tar.gz`，在 CPR 插件管理中上传并切换现有实例。现有配置、计划、历史和指纹库保留。包包含私有 Python/NumPy 运行时，要求 Linux x86_64、glibc 2.36+。

CPR 3.38.1 会按有效模型目录和账户模型限制检查原生 Responses 请求的账户资格。使用自定义模型时，需确保上游模型目录包含对应 ID，且所选 Key 与账户允许该模型。

安装包与 `.sha256` 校验文件随 Release 发布。单核构建与回归结果见 [验证记录](../verification.md)。
