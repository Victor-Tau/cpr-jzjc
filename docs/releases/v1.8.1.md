# v1.8.1

新增按检测结果筛选：**降智、未降智、其他**。

- 账户检测新增「检测结果」下拉框，默认显示全部；可与搜索、订阅、账户状态和分组筛选组合使用。
- 账户按最新一条检测记录归类：已完成且确认降智为「降智」，已完成且未降智为「未降智」；尚未检测、暂不支持、排队、检测中、失败、中断、取消、疑似降智、低置信度和证据不足等归入「其他」。
- 检测历史按每条记录提供相同的三类筛选，支持搜索和全选筛选结果批量删除。
- 切换筛选自动回到第一页；跨页选择保留，顶部检测队列和确认降智快捷筛选继续可用。检测结果自动刷新时同步更新筛选列表。

适配 **Codex Proxy RS >=3.32.0、<3.33.0**，Linux x86_64、glibc 2.36+。沿用 RPC v6、180 秒维护预算及私有 Python/NumPy 运行时，更新现有实例保留配置、计划、历史和指纹库。

前端和 Rust 发布构建均绑定 CPU 0，使用单个核心。验证范围和结果见 [验证记录](https://github.com/Victor-Tau/jzjc/blob/v1.8.1/docs/verification.md)。
