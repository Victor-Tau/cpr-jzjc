# v1.8.2

账户检测列表默认每页显示 **100 条**，减少翻页操作。仍可手动选择 10、20、50、100 条，筛选和跨页批量操作继续可用。

适用于 **Codex Proxy RS >=3.32.0、<3.33.0；Linux x86_64、glibc 2.36+**，包含私有 Python/NumPy 评分运行时。

安装包：`personal.modeltrace-health-1.8.2-x86_64-unknown-linux-gnu.tar.gz`。在宿主「插件管理」上传安装包并更新现有实例。

前端与 Rust 发布构建均固定使用一个 CPU 核心。按本次要求未执行任何 SHA-256 校验；打包工具仅生成安装格式需要的摘要字段及附件。

验证范围和结果见 [验证记录](https://github.com/Victor-Tau/jzjc/blob/v1.8.2/docs/verification.md)。
