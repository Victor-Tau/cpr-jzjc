## 账户与检测报告

账户页支持搜索名称、邮箱或账户 ID，并组合订阅类型、账户状态、分组和检测结果筛选。默认每页显示 100 条，可切换 10、20、50、100 条，支持当前页选择和跨页批量检测。当前支持 OpenAI 账户，其他提供方会显示暂不支持。

手动和定时检测使用同一套全局配置，但分别排队、去重和保留报告。同一账户已有活动自动任务时，仍可提交手动检测；活动手动任务也不会阻止定时任务提交。「停止手动队列」和「停止自动队列」分别取消对应来源，单个任务可在历史中取消。关闭页面后后台检测继续执行。

报告保留每轮候选概率、家族概率、触发原因、请求 ID、请求诊断、配置快照和指纹库版本。进行中的报告会自动刷新；历史自动保留最近 3 天，数量受宿主私有状态存储容量约束。可全选筛选结果批量删除历史；删除报告不会恢复已停用账户，也不会恢复原分组。活动任务及等待账户处理的记录不能删除。

账户页的结果筛选按账户最新记录归类：已完成且确认降智归入「降智」，已完成且未降智归入「未降智」；未检测、暂不支持、排队、检测中、失败、中断、取消及其余结论归入「其他」。历史页按每条记录使用相同分类。

## 默认参数

| 参数 | 默认值 |
| --- | --- |
| 请求模型 | `gpt-6.1-sol` |
| 降级模型名单 | `gpt-5.6-luna` |
| 低置信度阈值 | 20% |
| 降智阈值 | 90% |
| 连续确认轮数 | 1 |
| 低置信度额外复测 | 最多 1 轮 |
| 重试与复测间隔 | 10 秒 |
| 推理强度 / 输出上限 | `low` / 4096 tokens |
| 并行检测数 | 4，可设置 1–16 |
| 请求超时 | 120 秒；0 表示不设置插件请求超时，仍受宿主预算限制 |
| 定时检测 / 自动停用 / 自动移组 / 后台检查指纹库更新 | 关闭 |
| 历史保留 | 最近 3 天 |

请求模型可从宿主模型目录选择，也可手动输入。计量 Key 必须允许访问待测账户和请求模型。temperature、推理强度、输出上限等参数仍由宿主和上游校验，不支持的参数会终止任务并在报告中显示原因。

## 判定与复测

判定使用用户保存的阈值、降级模型名单和别名映射。以下数值以默认配置为例：

1. 最高候选概率严格低于 20% 时判为低置信度，按额外复测预算继续检测。
2. 请求模型经别名映射后不在降级名单内，最高候选在降级名单内，且概率至少为 90% 时，计入一次疑似降智结果；达到连续确认轮数后确认降智，其他结果中断连续计数。
3. 未触发降智规则且最高候选概率至少为 90% 时显示「未降智」，其余结果显示「证据不足」。

例如，请求 `gpt-6.1-sol`，一轮以至少 90% 的相对概率匹配到 `gpt-5.6-luna`，在默认规则下即确认降智。直接请求 `gpt-5.6-luna`，或将请求模型别名指向它时，匹配到该模型不会触发降智。

每轮获得一个有效回答后评分，普通失败最多进行 5 次采样尝试。无效回答、限流和超时会消耗尝试；认证、权限或参数错误立即终止。连续两次完整请求窗口的宿主预算超时也会提前终止。每个任务总轮数上限为「连续确认轮数 + 低置信度额外复测预算」，默认最多 2 轮、10 次请求，多数任务一轮结束。

概率只在当前候选库内有意义。库外模型仍会被分到现有候选，结果适合作为排查参考，不构成模型身份认证。

## 确认后处理

「关闭账户调度」和「移入指定分组」为两个独立开关，默认均关闭，可以同时开启。只有确认降智后才执行，失败或证据不足不会触发这些操作。

关闭调度会将宿主账户设为停用；移组会用指定的单个分组替换原有全部分组。两项操作独立保存结果，一项失败不会阻止另一项。报告中的重试只重试对应账户操作，不重新发送检测请求；账户已处于目标状态时跳过重复写入。

需要恢复时，由管理员在宿主中重新启用账户或调整分组。删除检测历史不撤销账户操作。

## 自动定时

支持固定间隔（分钟）和指定 IANA 时区的每日时刻。每日时刻遇到夏令时缺失分钟时，在之后首个有效分钟执行；重复时刻当日只执行一次。

检测范围可以是固定账户 ID，也可以组合多个订阅类型、状态、分组和关键词筛选。动态筛选会在每次运行时重新匹配，从而纳入新账户；订阅类型留空表示全部。定时检测仅选择启用的 OpenAI 账户，跳过已有活动自动任务的账户，每次最多提交 500 个账户，超出时需缩小范围。

手动检测不会改变自动计划的下次执行时间。错过的执行点合并为一次，不补跑全部历史时刻。「停止自动队列」取消已提交的自动任务；关闭后续计划需在参数配置中停用定时检测。

## 超时、进度与恢复

默认请求超时为 120 秒。执行器使用配置超时和宿主剩余预算中较短的窗口；0 表示不设置插件请求超时，仍不能突破宿主的有限调用预算。

插件声明 180 秒的维护预算，并为准备、并行结果保存、校验和评分保留时间。每批请求发出前检查完整窗口，预算不足时顺延到下一次维护，不消耗采样尝试。单次维护结束后，宿主约 30 秒再次调度；倒计时到零表示任务已可执行，仍需等待调度。

有效回答会先保存，再校验和评分。当前预算不足时，显示「已保存回答，等待校验」或「已获得有效样本，等待评分」，下次回调继续处理，不重复请求。达到超时或输出上限时，若已收到的部分正文通过原有数字样本校验，可继续评分，并在报告中标明部分结果；仅推理、数字不足或明确的上游失败不会被当作有效样本。

插件被取消、替换或重启后，会重新读取持久化状态：排队任务和已保存结果继续处理，已发出但没有保存结果的请求标记为中断，需要重新提交。结果不确定的请求不会自动重发。上游返回凭据撤销等认证错误时，需先在宿主刷新凭据或重新授权。

并行数控制同批账户的模型请求数量，校验、评分与状态保存仍串行执行。提高并行数会增加同时占用的模型流与收尾预算，可根据宿主容量调整。

## 配置备份与迁移

参数保存在宿主的插件私有状态中。使用宿主升级或版本切换功能更新现有实例，可保留配置、计划、历史、指纹库及提交去重信息。删除后新建实例不会自动继承原实例状态。

在「参数配置 → 配置备份」点击「导出配置」，复制完整 JSON 并保存为 `modeltrace-health-config.json`。宿主隔离页面提供可选中复制的内容；独立页面也可下载文件。导出仅包含已保存的参数、Key ID、分组 ID、定时范围和镜像地址，不含 Key 密钥、账户凭据、历史或指纹库，未保存的表单修改也不在备份中。

迁移时导入配置文件，校验后先载入表单；核对新环境的计量 Key、分组、账户 ID 与模型，再点击「保存全部参数」生效。未知字段、无效阈值或超过 250 KB 的文件会被拒绝。配置备份不能跨实例恢复检测历史或指纹库数据。

## 指纹库在线更新

在「参数配置 → ModelTrace 指纹库」点击「检查更新」，随后「下载并应用」。可开启后台定时检查，默认间隔 24 小时；应用更新仍需管理员点击。

来源固定为 [xqy2006/ModelTrace](https://github.com/xqy2006/ModelTrace) 默认分支的 `data/unified_bank.json`。插件先解析提交 SHA，再从固定提交下载，展示版本、摘要、建库时间、模型列表和模型增删变化。HTTPS 镜像前缀按 `镜像前缀/完整 GitHub 地址` 拼接。

下载上限为 20 MiB，压缩后存储上限为 3 MiB。新库需通过格式、指纹方法、维度、数值、校准参数及离线评分校验后才切换；不兼容时会提示升级插件。在线更新仅加载 JSON 数据，算法和 Python 运行时随插件版本更新。

可「回退上一版本」或「恢复内置库」。已开始任务及其复测始终使用原指纹库，旧报告保留当时概率，不随更新重新计算。新库移除配置中正在使用的降级模型或别名目标时，应用会被阻止，需要先处理冲突。下载或保存失败保留当前库。

## 常见问题

### 插件管理提示响应状态、内容类型或正文无效

先确认宿主与插件兼容。CPR 3.35.x 应使用 1.10.0；该版本修复历史或账户列表超过管理响应正文上限的问题，页面会自动合并分页数据。更新时切换现有实例到新版本，并重新打开插件页面。

若仍出现错误，反馈插件和宿主版本、发生的页面与操作、账户或历史的大致数量，以及脱敏后的错误信息。

### 请求超时或任务等待下一次维护

查看报告中的实际请求窗口、耗时和正文接收情况。配置超时、宿主剩余预算、网络期限与上游响应速度都可能影响结果。将配置设为 0 不能取消宿主预算；可以结合报告调整并行数或请求参数。

### 报告提示有效数字不足

评分使用数字指纹挑战的有效数字样本。至少需要 `max(80, ceil(期望数量 × 55%))` 个有效数字，至多 4096 个；部分回答末尾尚未完整输出的数字会被丢弃。只有推理内容、拒答或正文过短都可能无法满足门槛，应结合报告中的正文接收量和请求错误排查。

### 运行时无法启动

首次解包约需 91 MB 空间，运行目录必须可写、可执行。插件会跳过 `noexec` 临时目录，并在失败后清理残留、尝试 `/var/tmp`，兼容仅有 64 MB 临时目录的容器环境。

可在**宿主进程环境**中设置 `MODELTRACE_RUNTIME_DIR` 指定首选运行时目录，或通过 `TMPDIR` 调整系统临时目录。容器中请为该目录挂载足够空间并允许执行；异常信息会标出具体文件和系统错误。

### 自动任务没有覆盖某些账户

检查账户是否启用、是否为受支持的 OpenAI 账户、是否匹配当前筛选、是否已有活动自动任务，以及是否超过单次 500 个账户的提交上限。固定 ID 范围不会自动纳入新账户。
